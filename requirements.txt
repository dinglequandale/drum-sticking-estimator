# POST-INSTALL PATCH (madmom 0.16.1 on Python 3.10+ / numpy 1.24+):
# After (re)installing madmom you must patch one line in its vendored source,
# or beat tracking silently falls back to librosa. In
#   .venv/Lib/site-packages/madmom/features/downbeats.py  (~line 287)
# replace:  best = np.argmax(np.asarray(results)[:, 1])
# with:     best = np.argmax([r[1] for r in results])
# (numpy>=1.24 rejects the ragged-array build.) The collections/np-alias
# breakages are handled at runtime by src/_madmom_compat.py.
